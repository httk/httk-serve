.. py:function:: create_asgi_app(adapter, config = None, *, baseurl = None, debug = False, report_level = 'warning', report_context_levels = None, data_url = None)

   Create an ASGI application serving an OPTIMADE API for a backend or store.

   An absent ``baseurl`` makes the application derive a mount-aware URL from
   the request. An explicit value is authoritative. API endpoints requested
   under the unversioned base URL answer a 307 redirect to the same endpoint
   under ``/v1/`` (query string preserved, ``api_hint`` honored); the base URL
   landing page and ``/versions`` are served at the unversioned base.

   :param adapter: Backend providing the served schema/query callback, or an
       entry store whose configured OPTIMADE families are discovered lazily.
   :param config: Optional service configuration.
   :param baseurl: Public API base URL, or ``None`` for request-based derivation.
   :param debug: Enable application and backend diagnostics.
   :param report_level: Minimum report level collected per request.
   :param report_context_levels: Context-specific report levels.
   :param data_url: When serving an entry store, the location served in place
       of the leading ``data`` segment of ``files`` URLs that start with
       ``data/``, e.g. ``https://example.org/files`` or a root-relative
       ``/files`` resolved against each request's origin; the rest of the URL
       is percent-encoded and stored entries are unchanged.
   :return: Configured serving application.
   :raises TypeError: If ``data_url`` is given with an adapter rather than an entry store.
   :raises ValueError: If ``data_url`` names no location or is protocol-relative.


.. py:function:: create_index_asgi_app(config, *, baseurl = None, debug = False, report_level = 'warning', report_context_levels = None)

   Create an ASGI application for an OPTIMADE index meta-database.

   The index serves only discovery, links, and unversioned version
   negotiation; like :func:`create_asgi_app`, it redirects (307) API endpoints
   requested under the unversioned base URL to ``/v1/``. It has no backend
   adapter and performs no query calls. The supplied configuration is retained
   as the response metadata source; the
   composed application's caller owns its lifetime and configuration.

   :param config: Validated index metadata and configured database links.
   :param baseurl: Authoritative public index URL, or ``None`` for
       mount-aware derivation from each request.
   :param debug: Enable Starlette diagnostics.
   :param report_level: Minimum report level collected per request.
   :param report_context_levels: Context-specific report levels.
   :return: Configured serving application.
   :raises TypeError: If ``config`` is not an
       :class:`~httk.serve.optimade.model.config.OptimadeIndexConfig`.
